# 工作坊模板

编辑器工具栏中有 **模板** 按钮；核心库中提供同样的模板，供自定义界面使用。

| 模板                 | 内容                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| 事件风暴             | 便签类型图例（领域事件、命令、参与者、策略、读模型、外部系统、聚合、热点）以及带示例的时间线 |
| 客户旅程地图         | 人物画像与目标，旅程各阶段对应的行动、触点、想法、情绪（每阶段一个表情）、痛点和机会 |
| 用户故事地图         | 用户旅程，以活动和任务为骨架，故事按版本切分                             |
| 回顾                 | 哪些做得好、哪些需要改进、我们要做什么                                   |

模板会放在可视区域的中央——若该处已被占用，则放在白板现有内容旁边——随后被选中并显示在视图中，作为一步历史记录：撤销一次即可整体移除。所有对象都是普通的便签、图形、文本、框架或连接线，可像其他对象一样编辑。文本跟随 `locale` 属性（或页面语言）：俄语或英语。

## 在代码中

```ts
import { insertTemplate, listTemplates } from '@dskripchenko/board'

listTemplates('en') // [{ id: 'event-storming', title, description }, …]
const { ids, ops, bounds } = insertTemplate(board, 'story-map', { x: 0, y: 0 }, 'en')
doc.apply(ops)
```

`insertTemplate` 以给定点为中心放置模板，返回创建它的操作（新的 id，位于白板所有内容之上）、新 id 以及占据的区域。

# Редактор

```vue
<BoardEditor v-model="board" :locale="'en'" style="height: 720px" @change="onChange" />
```

## Свойства

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `modelValue` | `Board \| string \| null` | `null` | Доска — объектом или JSON-текстом. |
| `readonly` | `boolean` | `false` | Просмотр: перемещение, масштаб, мини-карта, экспорт. |
| `locale` | `string` | `lang` страницы | `ru` или `en`. |
| `labels` | `Partial<BoardLabels>` | — | Замена любого текста интерфейса. |
| `minimap` | `boolean` | `true` | Показывать мини-карту при старте. |
| `provider` | `BoardProvider \| null` | `null` | Совместная работа в реальном времени ([Совместная работа](collaboration.md)). |
| `user` | `{ id?, name?, color? }` | — | Кто редактирует: видно остальным. |
| `lockable` | `boolean` | `true` | Может блокировать и разблокировать доску для всех. |

## События

| Событие | Данные | |
|---|---|---|
| `update:modelValue` | `Board` | После каждого изменения. |
| `change` | `{ board, ops, origin }` | Применённые операции; `origin` — `local`, `undo`, `redo` или `remote`. |
| `selection` | `string[]` | Выделенные id. |

## Доступное снаружи

Через ref шаблона: `fit()`, `select(ids)`, `zoomTo(k)`, `toPng(scale?)`
(`Blob`), `toSvg()` (`{ svg, width, height }`), `applyRemote(ops)`, `doc`
(`BoardDoc`), `sync()` (`SyncClient`, когда задан поставщик).

## Инструменты

| Инструмент | Клавиша | |
|---|---|---|
| Выбор | V | Щелчок, Shift-щелчок, рамка выделения перетаскиванием. |
| Рука | H или удерживать Space | Перемещение по доске. |
| Стикер | N | Щелчком поставить; сразу печатать. Двойной щелчок по пустому месту тоже создаёт стикер. |
| Фигура | S | Щелчок — размер по умолчанию, или перетаскивание; повторный щелчок по инструменту — восемь видов. |
| Текст | T | Щёлкнуть и печатать: заголовок, подзаголовок или текст. |
| Блок | F | Щелчок или перетаскивание. Объекты, брошенные в блок, перемещаются вместе с ним. |
| Связь | L | Перетащить от объекта (или из любого места) к другому; концы прикрепляются к объектам. |
| Эмодзи | E | Выбрать, затем щелчком поставить. |
| Карандаш | P | Рисовать; повторный щелчок по инструменту — цвета и толщины. |
| Маркер | M | Широкий полупрозрачный штрих. |
| Ластик | X | Удаляет штрихи, которых касается (целиком). |

## Редактирование

- **Перемещение** перетаскиванием; края и центры прилипают к ближайшим
  объектам (удерживайте Alt, чтобы двигать свободно). Стрелки сдвигают на 1,
  с Shift — на 10.
- **Размер** меняется маркерами (Shift сохраняет пропорции), **поворот** —
  круглым маркером сверху (Shift — шаг 15°). Группа масштабируется целиком.
- **Текст:** двойной щелчок или Enter. Escape или Ctrl/⌘ + Enter завершает.
- **Связи:** перетащите маркер конца, чтобы прикрепить его заново.
- **Панель над выделением:** цвета, вид фигуры, заливка и линия, стиль
  текста, маршрут и стрелки связи, цвет и толщина штриха, выравнивание и
  распределение (несколько объектов), обвести выделение блоком, на передний
  план, на задний план, дублировать, закрепить, удалить.

## Клавиатура

| Клавиши | |
|---|---|
| Ctrl/⌘ + Z, Ctrl/⌘ + Shift + Z (или Y) | Отменить, повторить |
| Ctrl/⌘ + A, D | Выделить всё, дублировать |
| Ctrl/⌘ + C, X, V | Копировать, вырезать, вставить (простой текст становится стикером) |
| Ctrl/⌘ + ], [ | На передний план, на задний план |
| Delete, Backspace | Удалить |
| Ctrl/⌘ + =, − ; Ctrl/⌘ + колесо или щипок | Масштаб |
| Колесо или прокрутка двумя пальцами | Перемещение по доске |
| Shift + 1 | Вписать в экран |
| Escape | Снять выделение, вернуться к Выделению |

## Блокировка доски

Кнопка с замком (внизу справа) блокирует доску для всех: инструменты и
правка выключаются, плашка показывает, кто заблокировал, и остаётся только
**Разблокировать** — для тех, у кого `lockable`. Блокировка — часть доски
(`meta.locked`), передаётся как любое изменение и отменяется; сервер
отбрасывает изменения объектов, пришедшие во время блокировки, поэтому
перемещение в этот момент откатывается у всех одинаково.

## Экспорт

Кнопка загрузки (справа внизу) сохраняет PNG (2×), SVG или JSON доски —
выделение или всю доску, если ничего не выделено. Экспорт использует тот же
рендерер, что и экран.

## Оформление

Редактор использует токены кита и эти переменные, все переопределяемые на
`.bd-root`: `--bd-text`, `--bd-stroke`, `--bd-shape-fill`, `--bd-surface`,
`--bd-frame-fill`, `--bd-frame-stroke`, `--bd-frame-title`, `--bd-connector`,
`--bd-accent`, `--bd-canvas`, `--bd-dot`. Явные цвета объектов (цвет
стикера, заливка фигуры) в тёмной теме остаются как есть; текст на них
переключается между тёмным и белым ради контраста.

## Производительность

Рисуются только объекты в области видимости, а рендеринг объекта кэшируется,
пока он не изменится. Доска из 5 000 объектов открывается примерно за 0,3 с
и перемещается с частотой 60 fps. Ограничения: 10 000 объектов на доску;
штрих делится после 2 000 точек.

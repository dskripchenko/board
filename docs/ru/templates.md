# Шаблоны воркшопов

На панели инструментов редактора есть кнопка **«Шаблоны»**; в ядре — те же
шаблоны для собственного интерфейса.

| Шаблон                        | Что на нём                                                                    |
| ----------------------------- | ----------------------------------------------------------------------------- |
| Event storming                | Легенда видов стикеров (событие, команда, актёр, политика, модель чтения, внешняя система, агрегат, горячая точка) и шкала времени с разобранным примером |
| Карта пути клиента            | Персона и цель, этапы пути против действий, точек контакта, мыслей, эмоций (по лицу на этап), болей и возможностей |
| Карта пользовательских историй | Путь пользователя, активности и задачи как хребет, истории, нарезанные на релизы |
| Ретроспектива                 | Что прошло хорошо, что улучшить и что мы сделаем                              |

Шаблон ставится в центр видимой области — или, если там занято, рядом с
содержимым доски, — выделяется и приближается, одним шагом истории: одна
отмена убирает его целиком. Все объекты — обычные стикеры, фигуры, тексты,
блоки и связи, правятся как любые другие. Тексты следуют свойству `locale`
(или языку страницы): русский или английский.

## В коде

```ts
import { insertTemplate, listTemplates } from '@dskripchenko/board'

listTemplates('ru') // [{ id: 'event-storming', title, description }, …]
const { ids, ops, bounds } = insertTemplate(board, 'story-map', { x: 0, y: 0 }, 'ru')
doc.apply(ops)
```

`insertTemplate` ставит шаблон центром в точку и возвращает операции,
которые его создают (новые id, поверх всего на доске), новые id и занятую
область.
